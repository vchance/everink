# Naming

Chosen: **Everink**. "Ever" for endless, "ink" for drawing. Short, easy to say, and it reads well as a
library and as package prefixes (`everink-core`, `everink-sync`, `everink-web`, `everink-native`).

Checked 2026-11-10 on crates.io, npm and GitHub. Domains and trademarks were not checked.
